# Programming Knowledge Tester
### Десктопное приложение для проверки знаний в программировании с графическим интерфейсом на Python/Tkinter.

## 📋 Описание
### Programming Knowledge Tester — это интерактивное приложение-викторина, 
### которое помогает проверить и закрепить знания по различным языкам программирования и IT-темам. 
### Пользователь отвечает на вопросы, выбирая один из вариантов ответа, 
### а приложение подсчитывает результат и показывает статистику.

## ✨ Возможности
- 🎯 Выбор категории вопросов (Python, JavaScript, SQL, алгоритмы и др.)
- 🖱️ Удобный графический интерфейс на Tkinter
- 📊 Подсчёт правильных ответов и итоговый результат
- 🔀 Случайный порядок вопросов
- ~~⏱ Таймер на прохождение теста (soon!)~~
- 💾 Сохранение истории результатов в JSON
- 🏆 Отображение лучшего результата


## 🛠️ Технологии
- Python 3.10+
- Tkinter — встроенная библиотека для GUI
- JSON — для хранения вопросов и результатов
