# programming-knowledge-tester-pkt-
Programming Knowledge Tester - это интерактивное приложение-викторина, которое помогает проверить и закрепить знания по различным языкам программирования и IT-темам. Пользователь отвечает на вопросы, выбирая один из вариантов ответа, а приложение подсчитывает результат и показывает статистику.
